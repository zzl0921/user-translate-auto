# User Translate (Auto Translate)

基于 Bookyakuno 的 **User Translate**（GPL-3）修改扩充的版本。
在原版“手工提取文本 → 外部翻译 → 粘回合并”之外，新增了**自动翻译**：
用随包附带的 16 万条对照词典，把选中插件的界面文字自动替换成中文。

## 安装（Blender 4.1+）

1. `编辑(Edit)` → `偏好设置(Preferences)` → `插件(Add-ons)`
2. 右上角下拉箭头 → `从磁盘安装(Install from Disk…)`
3. 选择 `user_translate_auto-1.2.1.zip`
4. 勾选启用 **User Translate (Auto Translate)**

> 如果装过原版 User Translate，请先卸载旧的：模块名相同，会互相覆盖。

## 一次性设置

展开插件偏好设置：勾选「界面翻译」，语言选「简体中文」。

## 自动翻译

1. 在「搜索」框输入关键词过滤（如 `node`），下面会显示「匹配 4 / 31 个插件」；
2. 点 `选择插件并翻译`，在弹出列表里点目标插件；
3. 等 1~3 秒，面板显示 `提取 48 条 / 已翻译 45 条 / 待补 3 条`；
4. 界面文字立即变中文，无需重启。

辅助功能：

- `复制该插件的待补文字`：把未命中的原文复制到剪贴板；
- `刷新插件列表`：新装插件后手动刷新（平时会自动检测）；
- `覆盖已有 CSV`：重建该插件的词典（旧文件备份为 `.csv.bak`），用于修复列错位的坏文件。

## 原理与边界

- 只用 `bpy.app.translations.register()` 替换界面显示文字，**不修改任何插件代码**，不影响功能；
- 未命中的词条留空，不会出现乱码；
- 词典是 `user_files/*.csv`，两列：`"中文","English"`，可自行增删。

## 本版修复的已知问题

1. 写 CSV 时用了系统默认编码（中文 Windows 上是 GBK），导致词典乱码 → 统一改为 UTF-8；
2. 读到非 UTF-8 词典会中断整个注册流程 → 现在逐文件容错，必要时回退 GBK；
3. 「文件数据」面板会列出词典的全部条目（最多近 2 万行），一展开就卡死 → 现在每个文件只预览 20 条并显示总数；
4. 重新注册时旧词典名残留、列表无限增长 → 现在会清空；
5. 提取文字的正则不是 raw 字符串，产生 `SyntaxWarning` → 已修正；
6. 自动翻译重写 CSV 会丢掉本次没抽取到的旧词条 → 现在只增不减。
