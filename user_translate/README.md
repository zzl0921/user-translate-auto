# User Translate (Auto Translate)

> 版本 **1.1.0** · 作者 **zzl0921** · 许可 **GPL-3**
> 基于 [Bookyakuno](https://github.com/Bookyakuno) 的 *User Translate* 修改扩充。

把 Blender 第三方插件的英文界面变成中文——**只替换界面显示文字，不修改插件本身**。

## 安装

1. `编辑 → 偏好设置 → 插件` → 右上角下拉箭头 → **从磁盘安装** → 选本压缩包；
2. 勾选启用 **User Translate (Auto Translate)**；
3. 展开偏好设置 → 勾选「界面翻译」→ 语言选「简体中文」。

> 装过原版 User Translate 的话请先卸载旧版（模块名相同）。

## 用法

- **列表里勾选插件 = 翻译它**（没有词典的会自动生成），取消勾选 = 恢复原文；
- 行尾 **↻** = 重新翻译该插件；
- 搜索框 + `全部 / 翻译中 / 未翻译` 筛选；
- 顶部「启用界面翻译」是总开关。

## 机翻补翻（可选，默认关闭）

词典没有的词条可以调用机器翻译补上：

1. 勾选「启用机翻补翻」，填写接口（默认 `https://api.deepseek.com`）、模型（`deepseek-chat`）和 API Key；
2. 在列表里选中插件 → 点「机翻补翻选中插件」；
3. 只翻译缺失的界面文字，结果直接写回该插件的 csv。

> 会产生少量 API 费用；Key 明文存在 Blender 偏好设置里，也可用环境变量 `USER_TRANSLATE_API_KEY`。

## 词典

- 随包 194 份词典、约 20 万行，实测覆盖已装插件的 **91.5%** 界面文字；
- 格式：`"中文","English"` 两列，UTF-8，放在 `user_files/` 下，每插件一份；
- 未命中的词条会留英文，不会乱码，可「复制该插件的待补文字」导出补译；
- 「词典体检」可一键统计有效/异常/重复行；
- 「词典目录」可选外部文件夹，覆盖更新插件时词典不会被覆盖。

## 数据与卸载

- 词典：本插件目录下 `user_files/*.csv`（或你指定的外部目录）；
- 卸载：禁用插件后删除 `scripts/addons/user_translate` 目录即可；词典请自行备份。
