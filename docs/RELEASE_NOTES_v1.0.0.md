# v1.0.0 — User Translate (Auto Translate)

基于 [Bookyakuno](https://github.com/Bookyakuno) 的 *User Translate*（GPL-3）修改扩充：
把 Blender 第三方插件的英文界面变成中文，**只替换显示文字，不修改插件本身**。

## 安装

1. 下载下方 `user_translate_auto-1.0.0.zip`；
2. Blender → `编辑 → 偏好设置 → 插件` → 右上角下拉 → **从磁盘安装** → 选择该 zip；
3. 勾选启用 **User Translate (Auto Translate)**；
4. 展开偏好设置 → 勾「界面翻译」→ 语言选「简体中文」。

> 装过原版 User Translate 的话请先卸载旧版（模块名相同）。

## 本次更新

### 新增
- **按插件开关**：列表里勾上即翻译、取消即恢复原文；没有词典的插件会自动生成。
- **单行重翻（↻）**：插件升级后一键重建该插件词典。
- **搜索 + 筛选**：`全部 / 翻译中 / 未翻译`，列表自带滚动条。
- **新装插件提示**：检测到新插件时提示「要翻译吗？」，可批量翻译或忽略。
- **词典目录可外置**：词典放插件外，覆盖更新插件不会丢词典。
- **总开关**：一键停用全部翻译。

### 修复（原版遗留）
- CSV 以系统默认编码写入导致乱码 → 统一 UTF-8；
- 一份坏词典会中断整批注册 → 逐文件容错并回退 GBK；
- 「文件数据」面板铺开近 2 万行导致卡死 → 只预览 20 条；
- 注销词典时名字列表无限增长 → 已修复；
- 提取文本正则触发 `SyntaxWarning` → 已修复；
- 自动翻译重写 CSV 会丢旧词条 → 改为只增不减。

### 性能
- 启动注册 **5.7 s → 0.8 s**（1090 万条 → 约 18 万条）。

## 兼容性

- Blender **4.1+**（实测 4.5.9 LTS / Windows 11）
- 模块名保持 `user_translate`，可直接覆盖安装原版
